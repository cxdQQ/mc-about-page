# QWQ 我的世界材质介绍页 - 产品需求文档

## 1. 产品概述
一个展示"QWQ"品牌多款 Minecraft 材质包的介绍网站，支持图文和视频展示，并配备后台管理功能。
- 目标用户：Minecraft 玩家和材质包爱好者
- 核心价值：集中展示 QWQ 品牌的多款材质包，提供沉浸式的浏览体验，方便管理员维护材质介绍内容

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通访客 | 无需注册 | 浏览所有材质包介绍、查看图片和视频 |
| 管理员 | 管理员登录 | 编辑材质包介绍、上传/删除图片视频、管理材质包列表 |

### 2.2 功能模块
1. **首页**：导航栏、材质包卡片展示、品牌介绍 Hero 区域
2. **材质详情页**：材质包详细介绍、图片轮播、视频播放、材质特性展示
3. **后台管理页**：材质包 CRUD、内容编辑、图片视频管理

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 导航栏 | 品牌 Logo、页面导航链接、材质包下拉菜单 |
| 首页 | Hero 区域 | 品牌 Slogan、背景动画、渐入效果 |
| 首页 | 材质包网格 | 材质包卡片网格展示，每张卡片含封面图、名称、简短描述 |
| 材质详情页 | 材质信息 | 材质名称、版本、作者、发布日期等基本信息 |
| 材质详情页 | 图片展示 | 支持多张截图轮播/画廊展示 |
| 材质详情页 | 视频展示 | 嵌入材质展示视频，支持多个视频 |
| 材质详情页 | 详细介绍 | 材质特性列表、详细描述、下载链接 |
| 后台管理 | 登录 | 管理员登录界面 |
| 后台管理 | 材质列表 | 所有材质包的管理列表，支持排序和搜索 |
| 后台管理 | 编辑页面 | 编辑材质包名称、描述、上传/删除图片视频 |

## 3. 核心流程
1. 访客访问首页 → 浏览材质包卡片网格 → 点击感兴趣材质包 → 进入详情页查看完整介绍
2. 管理员登录后台 → 查看材质列表 → 点击编辑 → 修改内容/上传图片视频 → 保存发布
3. 管理员添加新材质包 → 填写基本信息 → 上传封面图 → 添加介绍图片和视频 → 发布上线

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深色主题为主，搭配 Minecraft 风格的翠绿色 (#4ade80) 作为强调色，玻璃质感效果
- **按钮风格**：玻璃质感 (Glass UI)，圆角，微光效，悬停时加深
- **字体**：标题使用 "Minecraft" 风格字体或粗体无衬线字体，正文使用清晰易读的字体
- **布局风格**：全屏卡片式布局，顶部固定导航栏，材质包以网格形式展示
- **动画效果**：页面加载时卡片渐入动画，悬停时放大和光效，滚动时视差效果

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | 导航栏 | 玻璃效果固定导航栏，品牌 Logo，导航链接，移动端汉堡菜单 |
| 首页 | Hero 区域 | 全屏 Hero，大标题，副标题，背景粒子或渐变效果 |
| 首页 | 材质包网格 | 3列响应式网格，玻璃卡片，封面图，名称，标签，悬停效果 |
| 详情页 | 顶部区域 | 材质包大封面背景，标题叠加，返回按钮 |
| 详情页 | 图片画廊 | 横向滚动或网格画廊，点击放大查看，支持缩略图导航 |
| 详情页 | 视频区域 | 嵌入视频播放器，支持多个视频切换 |
| 详情页 | 内容区域 | 材质特性列表（图标+文字），详细描述，下载按钮 |
| 后台 | 登录页 | 简洁的玻璃卡片登录表单 |
| 后台 | 仪表盘 | 侧边导航，材质列表表格，操作按钮 |
| 后台 | 编辑页 | 表单字段，图片/视频上传区域，预览功能 |

### 4.3 响应式设计
- 桌面优先，适配平板和手机端
- 桌面端：3列材质网格，固定导航栏
- 平板端：2列材质网格，折叠导航栏
- 手机端：1列材质网格，底部导航或汉堡菜单

### 4.4 响应式设计补充
- 图片和视频使用懒加载优化性能
- 图片使用 next/image 进行优化
- 视频使用 HTML5 video 标签，支持多种格式
